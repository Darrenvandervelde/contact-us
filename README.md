# Contact Us

A contact form website currently in its testing phase.

## Planned technology

- **Frontend:** React, Vite, TypeScript and CSS
- **Backend:** Node.js, Express and TypeScript
- **Database:** To be confirmed

## Planned contact form

The form will collect:
- Name
- Email address
- Subject
- Message

It will include client- and server-side validation, plus clear success and error feedback.

## Project structure

The application will be organised into separate frontend and backend folders:

```text
contact-us/
├── client/       # React + Vite frontend
├── server/       # Express API
├── .env.example  # Environment variable template
├── .gitignore
└── README.md
```
